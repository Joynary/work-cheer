# 上班鼓励器

一个离线优先的薪资与愿望进度 PWA。无需注册、广告或后端服务；薪资设置、计时状态和愿望清单保存在浏览器本机。

## 功能

- 按月薪、每月工作天数、双休或大小周自动折算时薪。
- 自定义班次、午休时长和大小周参照周。
- 显示今日收入估算、工作进度和每月累计。
- 添加愿望及预算，估算达到目标还需工作的时间。
- 支持安装到支持的手机或桌面浏览器，且可离线打开。
- 提供 ZIP 源码下载，便于自托管和后续更新。

收入估算不含税费、加班费、补贴和实际工资单误差。大小周按周一至周日、以设置的参照周交替计算；不计薪休息时段按班次中点估算。

## 本地运行

```sh
python -m http.server 4173 --directory work-cheer
```

打开 `http://localhost:4173`。PWA 安装和离线功能需要 HTTPS 或 localhost。

## 发布

推送到 `main` 后，GitHub Actions 会把 `work-cheer/` 发布到 GitHub Pages。推送 `v*` 标签会生成 Release，并提供可下载的 `work-cheer.zip` 软件包。
